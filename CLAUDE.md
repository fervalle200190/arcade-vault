## Stack notes that differ from older Next.js

- **Next.js 16 + React 19, App Router only.** `AGENTS.md` (imported above) is authoritative: read the guide under `node_modules/next/dist/docs/01-app/` before writing routing, data-fetching, or caching code — this version's APIs differ from pre-15 training data.
- **Typed routes are global.** `app/layout.tsx` uses `LayoutProps<"/">` without importing it; `PageProps<...>` works the same way. These types are generated into `.next/types` and `.next/dev/types` (both are in `tsconfig.json` `include`), so typechecking a clean checkout needs a `next dev`/`next build` first.
- **Tailwind v4, CSS-first config.** There is no `tailwind.config.js`. `app/globals.css` does `@import "tailwindcss"` and declares design tokens in an `@theme inline` block; add colors/fonts there, not in a JS config. PostCSS wires it via `@tailwindcss/postcss`.
- `@/*` maps to the repo root in `tsconfig.json`.
- The `<!-- BEGIN:nextjs-agent-rules -->` block in `AGENTS.md` is regenerated by `next dev`. Don't strip it from a diff — commit it along with your work.
